Task Manager REST API
Welcome to the Task Manager REST API! This application, developed by Asoh Yannick, a Full-Stack TypeScript Developer, is designed to help users and administrators efficiently manage tasks. Built with Node.js, Express.js, MongoDB, and TypeScript, this API provides a robust set of features for task management.

Users can create tasks, fetch all tasks or a single task, update tasks, and delete them as needed. Additionally, the API supports advanced search functionalities, allowing users to sort, filter, and paginate through tasks seamlessly. For secure access, I have implemented JSON Web Tokens (JWT) for user and admin authentication, ensuring that your data remains protected.

Feel free to explore, contribute, and enhance your task management experience with this API!
